THE KING'S CHESS CLUB WEBSITE
=============================

Files:
- index.html: complete responsive one-page website
- assets/kings-chess-club-logo.png: standalone club logo

Preview:
Open index.html in a modern browser. The layout adapts to desktop, laptop, tablet, and phone widths.

Before publishing:
1. Upload the contents of this folder to your website host.
2. The chess/club photos load from Unsplash, so visitors need an internet connection to see them.
3. The current logo image is included as provided. If you want a logo with exact typography/spacing, replace assets/kings-chess-club-logo.png with your approved final logo file.
4. The site currently uses the launch date Thursday, October 15, 2026, weekly hours 4:00–6:00 PM, the church address, and Paul’s contact number from the supplied club details.
5. This is a static website; it does not yet include a custom domain, hosting, email form backend, or analytics.

To customize:
Edit index.html with any text editor. Styles are in the <style> section near the top.
